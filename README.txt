MIRACLE LUXE BEAUTY — WEBSITE STARTER
=====================================

Your website files:
- index.html   = page structure
- styles.css   = colours, layout, mobile/computer design
- app.js       = displays products and builds WhatsApp order messages
- config.js    = shop name, WhatsApp number, greeting and currency
- products.js  = products, prices, descriptions and photo links

IMPORTANT BEFORE PUBLISHING
1. The four products and prices are SAMPLE CONTENT. Replace them with your actual products, prices and real product photos.
2. The WhatsApp number is currently set to 2347025227905.
3. Product orders open WhatsApp with a prepared message. The customer still has to press Send.
4. This is a static website. It has no customer accounts and no payment system.

HOW TO EDIT ON ANDROID
1. Download and extract the ZIP using your phone's Files app.
2. Open the extracted folder in an editor such as Acode or Spck.
3. Open config.js to change your shop name, WhatsApp number or welcome message.
   Example number: "2348012345678" (digits only; no plus sign or spaces).
4. Open products.js to edit product names, prices, categories, descriptions and photos.
   - Use category "Beauty" for cosmetics.
   - Use category "Perfume" for perfumes.
   - Price should be a number without commas, e.g. 12500.
   - For a new product, copy one full product block and give it a unique id.
   - Photo can be a direct image URL or a relative file path such as "images/my-perfume.jpg".
5. Save, then open index.html in your editor's preview/browser to test it.

HOW TO PUBLISH FREE
You can publish the folder using a free static hosting service such as GitHub Pages or Netlify.
After you edit the files, upload/redeploy the updated files for changes to appear for all visitors.
A free hosting address is usually provided; buying a custom domain is optional.

OWNER EDITING NOTE
The site intentionally keeps editing simple: change config.js and products.js. Changes made only in your phone's local preview do not automatically update the live website. Upload/redeploy the edited files to publish changes.
